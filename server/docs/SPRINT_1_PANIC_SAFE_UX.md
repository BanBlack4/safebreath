# SafeBreath AI: Sprint 1 — PANIC-SAFE MICROINTERACTIONS

## Psychologically Safe Choreography
Every modal, transition, alert, and loading state is audited for emotional safety:
*   **No Sudden Pops:** Alert modals do not spring out. They gently rise.
*   **Safe Reconnection:** If BLE reconnects, there is no green flash. The "Offline" pill simply fades out.
*   **Deliberate Friction:** The SOS slider is the only element that requires physical exertion. Everything else (dismissal, breathing start) requires only a gross motor skill tap, accounting for trembling hands.
