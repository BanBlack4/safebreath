# SafeBreath AI: Phase 3 — CALM INTERVENTION EXPERIENCE

## The "World-Class" Fullscreen Intervention
When an anomaly hits, the app must transform from a passive observer into an active grounding tool. 

## World-Class Visuals
*   **Immersion Backdrop:** We cast an `absolute inset-0 bg-gradient-to-br from-slate-900 via-slate-950 to-teal-950 opacity-80` to completely wipe out the background UI and focus the eye downward.
*   **The Breathing Core:** Two beautifully blurred, overlapping circles (`mix-blend-screen`, `blur-2xl`) expand and contract. This creates an ethereal, volumetric glowing lung effect rather than a cheap SVG slider.

## Emotional Regulation UX
*   The text prompt is incredibly polite: *"¿Te sientes bien? Notamos un aumento inusual en tu ritmo cardíaco."* 
*   **Escalation slider:** The SOS dispatch requires a physical "Slide to Dispatch" slider. It uses a deep red, not a bright laser red, matching emergency protocol while lowering light pollution into the user's eyes.
*   **Dismissal:** The "Estoy Bien" buttons do not feel permanent; they let the user instantly drop back to safety if it was a false alarm.
